# Gloss Craft

Turn each mapped sense into a target-language meaning that is both faithful to
the monolingual source and natural to read.

## What a good gloss has

- **Faithfulness**: covers the monolingual definition, nothing added, nothing lost.
- **Naturalness**: phrased the way a dictionary in the target language phrases it.
- **Disambiguator**: a parenthetical context cue up front —
  "(of taste)", "(of a face)", "(slang)" — so the user picks the right sense at a glance.
- **Example where it earns its place**: one short example for slang, register-heavy,
  or easily misused senses (微妙だね "(it's) questionable, meh [slang]").
- **Source citation**: dictionary name + sense number, kept alongside the gloss
  in your notes and (briefly) for the user.

## Anti-patterns (never do these)

1. **Translationese** — word-for-word renderings that no native speaker would write.
2. **Over-merge** — one gloss spanning two monolingual senses ("sullen taste" for 渋い).
3. **Dropped nuance** — losing transitive/intransitive, aspect, or register information.
4. **Memory glossing** — writing any sense without a quoted monolingual source.
5. **Unlabeled register** — slang/formal/archaic senses presented as neutral.

## Citation format (working notes + user-facing)

```
sense 2 "sullen, glum (of a face)" ← 新明解 sense 2; 明鏡 agrees
```

Present the same compactly to the user so they can verify you. Traceability is
the whole point: anyone can check every meaning against its source.
